# V10 OBB训练记录

## 目的

在不覆盖V9分割模型的前提下，验证旋转框能否更稳定地给出规则泡沫块的几何中心，并额外输出目标朝向。

## 数据构建

- 来源：`data/training/foam_center_v9/`。
- 转换：对每个已审查的可见泡沫轮廓拟合最小面积旋转矩形。
- 划分：完全继承V9；不同背景录像整段只用于验证。
- 训练：522正样本、197负样本。
- 验证：76正样本、79负样本。

## 训练环境

- 模型：YOLO11s-obb预训练权重。
- GPU：NVIDIA RTX 4070 Laptop GPU。
- Python 3.12.9、PyTorch 2.6.0+cu118、Ultralytics 8.4.33。
- 输入尺寸640，batch 8，计划60轮，patience 12。
- 第28轮自动早停，最佳结果在第16轮。

## 最佳训练指标

| 指标 | 结果 |
| --- | ---: |
| Precision | 0.99851 |
| Recall | 1.00000 |
| mAP50 | 0.99500 |
| mAP50-95 | 0.88425 |
| 单张模型推理 | 约2.9 ms（训练验证日志） |

## 同一几何中心定义下的对比

以下两者都以V10旋转框标签中心为参考，置信度0.30：

| 指标 | V9分割混合中心 | V10 OBB中心 |
| --- | ---: | ---: |
| 正样本召回 | 100% | 100% |
| 79张负样本误检 | 2 | 0 |
| 平均中心误差 | 6.23 px | 6.04 px |
| 中位中心误差 | 4.50 px | 3.68 px |
| P95中心误差 | 20.07 px | 26.18 px |
| 平均运动平面角误差 | 0.507° | 0.435° |
| P95运动平面角误差 | 1.491° | 1.495° |

V10降低了平均/中位中心误差并消除了该验证集上的负样本误检，但困难样本尾部误差更大。因此它是一版有效候选模型，还不足以在未经实时回放修改和验证前直接替换V9。
