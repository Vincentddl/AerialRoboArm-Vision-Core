# HC-13视觉自动转角

## 控制链路

```text
泡沫目标中心
  -> 鱼眼标定得到镜头光轴偏移角
  -> 舵机—视觉查找表反算HX8绝对g角度
  -> 连续5帧稳定性确认
  -> COM5 / HC-13发送整数角度
  -> MCU USART3解析
  -> RC监督下的AUTO模式
  -> HX8转到目标g角度
```

发给MCU的是标定后的`servo_command_deg`，不是原始镜头偏移角。协议为：

```text
V,<servo_g整数角度>,<速度>,<置信度>\r\n
```

默认示例：

```text
V,-70,0,91\r\n
```

`速度=0`表示目前使用MCU端的AUTO默认速度。

## 默认发送条件

- YOLO置信度不低于60%。
- 目标位于单轴机械臂平面容差内。
- 目标偏移角位于当前无红点舵机实测节点范围内，`g=-97°~-47°`。
- 同一个追踪目标连续确认5帧。
- 5帧舵机目标角的极差不超过2°。
- 预览窗口中已经按`A`键将HC-13输出置为`ARMED`。

锁定后按20 Hz发送，保证小于MCU的200 ms视觉超时。目标消失、越界、置信度不足或角度不稳定时立即停止发送；MCU超时后保持最后位置。

## 启动和操作

1. 将PC侧HC-13接入并确认设备显示为`COM5`，参数为`230400 8N1`。
2. 烧录本次构建的MCU固件。
3. 先让机械臂处于安全支撑状态，保留急停操作空间，RC暂时保持手动或空闲模式。
4. 在项目目录启动：

   ```powershell
   & 'D:\app\miniconda\envs\python312\python.exe' run_realtime.py
   ```

5. 确认画面显示正确的`optical`与`servo_g`，再按`A`。画面应显示`HC13 ARMED`。
6. 将RC模式切换到AUTO。只有MCU确认RC在线、舵机在线、没有急停/锁存故障且视觉包新鲜时才会转动。
7. 再按`A`会停止发送；按`Q`或`Esc`退出程序。停止后约200 ms，MCU进入视觉超时保持。

如果只想检查视觉、不允许发送，可使用：

```powershell
& 'D:\app\miniconda\envs\python312\python.exe' run_realtime.py --no-hc13
```

## 画面状态含义

- `HC13 SAFE DISARMED - PRESS A`：串口已打开，但发送权限关闭。
- `CONFIRMING 3/5`：目标有效，正在累计稳定帧。
- `UNSTABLE`：连续帧的目标角波动超过2°，不发送。
- `LOCKED g=-70deg`：已经锁定并周期发送该整数目标角。
- `NO VALID TARGET`：目标丢失、越出机械臂平面/标定范围或置信度不足。
- `LINK ERROR`：COM5不存在、被其他程序占用或串口发生错误。
