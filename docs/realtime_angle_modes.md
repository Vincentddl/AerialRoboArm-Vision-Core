# 实时角度定义与运行模式

## 当前推荐入口

```powershell
python run_realtime.py
```

程序固定使用 `target-mode=current`：输出最新的、连续两帧确认后的 YOLO 检测中心，不计算 0.4 秒后的预测位置。

无红点中心验证时使用 `--show-centers --no-hc13`。画面中的白色 `C(x,y)` 十字是模型本帧测得的目标中心；该模式只显示和记录，不向单片机发送命令。

## 四个角度字段

- `optical_axis_offset_deg`：目标中心射线与镜头光轴在机械臂单轴运动平面内的夹角；画面中轴线为 0°，向下为正。
- `servo_command_deg`：当前入口根据 2026-08-16 无红点泡沫中心 V1 查找表，反算得到的舵机 `g` 命令角。
- `legacy_mechanical_angle_deg`：旧机械水平定义，等于光轴偏移角加镜头向下安装角 30°。
- `lateral_angle_deg`：目标相对机械臂运动平面的左右偏角，只用于判断单轴机械臂能否抓取。

当前无红点关系的实测节点范围为 `g=-97°` 到 `g=-47°`，运行配置的边界容差为 `2°`。边界容差允许显示接近端点的估计值，不等于在节点范围外重新做过实测；自动控制前仍应核对物理范围。

自动模式的关系是：

```text
YOLO检测外部目标中心 → 目标光轴偏移角 → 反查泡沫中心 V1 表 → 目标舵机角
```

红点 V3 表保留给专门的夹爪视线监视器；当前无红点实时入口直接使用泡沫中心 V1 表。

## 齿轮关系

舵机 40 齿、从动轮 48 齿，并且是外啮合：

```text
从动轮角度增量 = 舵机角度增量 × (-40/48)
```

这一传动效果已自然包含在舵机—视觉实测关系中，实时程序不会再次乘齿轮比。尚未确定从动轮机械绝对零位，因此当前不输出绝对从动轮角。

## 保留的实验模块

`vision/ballistic_predictor.py`、`vision/trajectory_predictor.py` 和 `vision/bearing.py` 是旧预测实验的兼容模块。推荐入口不会启用它们，保留它们是为了让历史测试和离线研究仍可复现。

## 红点舵机角度监视器

`run_servo_angle_monitor.py` 使用红色圆点中心和 `configs/servo_to_optical_angle_red_marker_lut_20260815_v3.json`，实时输出 `inferred_servo_angle_deg`。查表覆盖 `g=-100°～-45°`，节点间采用线性插值。`20260813_v2` 保留为本次机械滑移前的备份，`20260806_v1` 保留为更早的历史版本。

该输出表示视觉反推的舵机 `g` 等效角度，不是 HX8 编码器回读值。红点拆除后，这个专用验证入口将无法检测；主程序 `run_realtime.py` 使用 YOLO 泡沫中心和独立实测的无红点 V1 表。旧线性配置继续保留作历史对照。
