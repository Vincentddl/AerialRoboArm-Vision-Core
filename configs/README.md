## `camera_2p1mm_640x480_fisheye.json`

- 状态：**当前使用**。
- 含义：2.1 mm 鱼眼相机的内参矩阵、鱼眼畸变系数和光心位置。
- 来源：9×6 内角点、20 mm 方格的棋盘标定，使用 53 张有效图像。
- 标定重投影误差：0.2286 px。
- 作用：把图像像素点校正并换算成相对于镜头光轴的视线角。
- 限制：仅适用于该镜头、焦距/对焦状态和 640×480 分辨率。移动镜头内部结构或改变分辨率后应重标定。
